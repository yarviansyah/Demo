# Hidrogen Hijau Berbasis Panas Bumi — Website Riset Doktoral

Website statis dwibahasa (Indonesia/English) untuk riset doktoral **"Kerangka Kuantifikasi Risiko dan Ketidakpastian Probabilistik Terintegrasi untuk Produksi Hidrogen Hijau Berbasis Panas Bumi di Indonesia"** (Yoga Arviansyah, Program Doktor Teknik Mesin, FTMD ITB).

Bilingual static website (Indonesian/English) for the doctoral research *An Integrated Probabilistic Risk and Uncertainty Quantification Framework for Geothermal-Based Green Hydrogen Production in Indonesia*.

## Isi / Contents
- `index.html` — Beranda / Home
- `literatur.html` — Kajian literatur / Literature review
- `matriks.html` — Matriks state of the art interaktif / Interactive SotA matrices
- `metodologi.html` — Kerangka QRA–ketidakpastian–LCOH / Framework
- `eksperimen.html` — Rencana eksperimen X52 dalam gas H₂ / X52 hydrogen test plan
- `rencana.html` — Linimasa dan luaran / Timeline and outputs
- `pustaka.html` — Daftar rujukan dan unduhan / References and downloads
- `tentang.html` — Tentang dan label verifikasi / About and verification labels

Tidak memerlukan build tool: semua halaman HTML, CSS, dan JavaScript murni. Diterbitkan dengan GitHub Pages (branch `main`, folder root).
No build step required: plain HTML, CSS, and JavaScript. Published with GitHub Pages (branch `main`, root folder).

Tambahkan `?lang=en` pada URL untuk membuka versi bahasa Inggris. / Append `?lang=en` to open the English version.
